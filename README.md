# 조선왕조실록 Android 2.0.0

공식 실록 사이트를 열람하면서 휴대폰 TTS 엔진을 선택해 문장/문단/줄 단위로 연속 낭독할 수 있는 개인용 독서 앱 프로젝트입니다.

## 음성/AI
앱은 Android에 TTS 엔진으로 등록된 엔진을 자동 검색합니다. 삼성/Google 등 제조사 음성이나, 기기 제조사가 AI 음성을 일반 TTS 엔진으로 공개한 경우 선택할 수 있습니다. 특정 AI 서비스가 TTS 엔진으로 공개되지 않았다면 앱에서 강제로 호출할 수 없습니다.

## 빌드
Android Studio에서 프로젝트를 열고 Sync 후 Build > Generate App Bundles or APKs > Generate APKs를 선택하십시오.

## 주의
이 버전은 공식 사이트를 데이터 원본으로 사용합니다. 국역 등 저작권 표시가 있는 콘텐츠를 앱에 대량 내장하지 않습니다. 완전 오프라인 eBook 데이터 패키지는 공식 이용조건을 확인한 뒤 별도 구축하는 것을 권합니다.
